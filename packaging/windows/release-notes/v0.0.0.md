This first Windows desktop preview packages the multiphy launcher and viewer with
Python, Qt and the core scientific libraries. You can install and run it without
setting up Python or uv. The existing Python/uv installation remains supported.

## Install

- **[Installer](https://github.com/jwingert/multiphy/releases/download/v0.0.0/multiphy-0.0.0-windows-x64-setup.exe):**
  install for your user account, then open the **multiphy** shortcut.
- **[Portable ZIP](https://github.com/jwingert/multiphy/releases/download/v0.0.0/multiphy-0.0.0-windows-x64-portable.zip):**
  extract the entire ZIP and open `multiphy-gui.exe`. Keep `multiphy.exe`, `_internal`
  and the other extracted files together.

`SHA256SUMS.txt` contains the download hashes. This initial prerelease is unsigned;
Windows may show a publisher or application-control warning.

On first launch, choose a folder for your projects, such as
`C:\Users\you\multiphy-data`. Keep it outside the application folder. You can choose
an existing multiphy data root, and the launcher remembers your selection.

## Included

- Recording import, field guidance and raw voltage feature extraction.
- The built-in `functional_likelihood` and `pair_logistic` matchers.
- The viewer, keyboard matching and review, curation history and accepted-track export.
- Project checks and the `multiphy.exe` command-line interface.

UnitMatch, DANT and DeepUnitMatch are optional and are not bundled. Provision those
backends and any model checkpoints through the Python installation. An external
backend interpreter selected in the launcher must have the same multiphy version
installed.

## Verification

Local checks of both the portable and installed application passed the synthetic
recording workflow: import, raw extraction, file verification, both built-in matchers,
accepted-track export, and launcher/viewer rendering. These checks used paths with
spaces and Unicode characters, with Python removed from `PATH`.

Updates are explicit downloads. Close active jobs and the application before
installing a newer version; keep your existing project data folder.

See the [desktop guide](https://github.com/jwingert/multiphy/blob/main/multiphy/docs/desktop.md)
and [Python/uv setup](https://github.com/jwingert/multiphy#python--uv-installation).
The [6½-minute video walkthrough](https://youtu.be/b9Ok8NqrHss) demonstrates recording
import, extraction, matching and accepted-track export.
